# 裸眼 3D 魚缸（head-coupled perspective）

用 webcam 偵測雙眼的位置與距離，即時重畫畫面，讓螢幕像一扇窗：頭往左就看到物體右側、靠近視野變大。
單一檔案 `index.html`，不用安裝；需要 HTTPS 或 localhost 才能開攝影機。

```bash
python -m http.server 8770      # 在這個資料夾，然後開 http://localhost:8770/
```

部署到 GitHub Pages 後在 `https://<帳號>.github.io/<repo>/3d/`。

## 原理

1. **眼睛 3D 位置**：MediaPipe Face Landmarker（478 點含虹膜）。虹膜直徑約 11.7 mm，所以
   `Z = 焦距(px) × 1.17cm ÷ 虹膜像素寬`，再由眼睛在影像中的位置反推 X、Y（攝影機在螢幕上緣外，換算成相對螢幕中心）。
2. **偏軸投影**：螢幕 = 固定在 z=0 的矩形窗，視錐四邊由「螢幕邊緣相對眼睛的位置」決定（Kooima 公式），
   場景單位是公分；盒子牆壁貼齊螢幕邊緣，物體可在螢幕後面（z<0）或浮出來（z>0）。
3. **眼球在眼眶**：虹膜中心相對兩眼角中點的偏移（−1~+1），目前只用來顯示與「視線聚光燈」（實驗）。
   網路攝影機的解析度不夠做精準視線追蹤，所以視差用的是「頭 / 眼睛位置」，不是視線方向。

## 準確度怎麼調

- 設定裡輸入**螢幕對角線**（影響實體大小，決定幾何對不對）與**攝影機視角**（筆電多為 60–75°）。
- 坐在已知距離（例如用尺量 50 cm）按「校準距離」。
- 全螢幕（F）時幾何最準；視窗模式下程式會用視窗位置估計偏移。
- 立體感 >1 會誇張視差（真實感差一點，但更明顯）。

## 驗證狀況

用「滑鼠模擬」和 `window.__setEye(x,y,z)` 驗證過：偏軸投影正確（眼睛往右 → 看到左牆、物體依深度位移不同）；
臉部模型能載入並執行。**真實臉部的距離與位置數值還沒用實際攝影機驗證**（開發環境沒有攝影機）。

## 方向與真實感調校（v2）

- **正確的視差**：像透過窗戶看外面——頭往右，螢幕後方的遠物體會往右移、近物體往左並露出側面。若你感覺相反，多半是攝影機畫面被鏡像，到設定按「**校準方向**」（3 秒內把頭往自己右邊移），或手動勾「左右反轉／上下反轉」。
- **距離**：改用「虹膜寬度」與「兩眼虹膜 3D 距離（瞳距）」兩種估計取平均，轉頭時不容易亂跳；「校準距離」會同時校正兩者。
- **延遲**：x/y 用低延遲 One Euro 濾波，並用速度做小幅前饋（約 45 ms），減少「慢半拍」造成的反向感；距離 z 濾得較重以免忽近忽遠。
- **眨眼**：偵測到眨眼／瞇眼時略過該幀，避免畫面突然跳動。
- HUD 新增「頭部移動」箭頭，可核對偵測方向與實際動作是否一致。

注意：攝影機實機表現未在開發環境驗證，若仍不自然請回報感覺（偏快／偏慢／方向）。

## 視角偵測、新場景與遊戲（v3）

- **頭部姿態**：抬頭／低頭、左右轉頭、歪頭，由臉部 3D 特徵點（兩側臉頰、額頭—下巴）的深度差算出，所以「抬頭」跟「頭往上移」是兩回事：
  頭**平移**＝視窗視差（遠物體跟著動）；頭**轉動**＝視角牽動（內容隨抬頭／轉頭轉動）。眼睛繞脖子轉出的那一小段位移（約 10 cm）會被扣掉，避免被誤判成平移。
  開頭 30 幀自動歸零，也可按「視角歸零」或 Z。方向相反就勾「轉頭／抬頭方向反轉」。滑鼠模式按住 Shift 移動 = 轉頭／抬頭。
- **新場景「浮出」**：棋盤格地板（所有場景都有）、五排不同深度的柱子、浮出螢幕前方的物體，視差最明顯；加了遠景霧化。
- **遊戲**（設定面板或 B / D 鍵；空白鍵、點擊、張嘴 = 射擊／重來）：
  - 🫧 **泡泡獵人**：45 秒，頭轉到哪準心就在哪（準心是眼睛沿頭部朝向射向螢幕的點），張嘴或點擊射擊，也可瞄準停留 0.8 秒自動擊破；越遠分數越高，金色泡泡 +50 分 +3 秒。滑鼠模式直接用滑鼠瞄準。
  - 🚀 **隧道閃避**：頭往上下左右移動，讓飛船穿過一道道牆的洞口，3 條命，越來越快、洞越來越小。倒數結束時的頭部位置 = 中心點。
  - 最高分存在瀏覽器 localStorage。
- 實機尚未驗證：姿態正負號、張嘴閾值（唇距/臉高 > 0.075）、準心靈敏度（頭轉角 ×1.5）。有問題請回報，或用方向反轉選項調整。

## 視線雷射點、旋轉中心、視覺化校正（v4）

- **視線雷射點**：視線落點 = 頭部朝向 + 眼球在眼眶的偏移，沿「眼睛 → 視線方向」打到螢幕平面，用紅色雷射點標出（設定可關）。聚光燈也改成放在這條射線的延長線上。
- **眼球看哪、視角偏哪**：設定「視線牽動畫面」把一部分視線偏移加進眼睛位置（預設 0.25），眼球轉動不再幾乎沒反應；「眼球靈敏度」放大眼珠位移（預設 1.5）。
- **旋轉中心 = 眼睛**：抬頭／轉頭／歪頭的「視角牽動」改成繞著眼睛位置旋轉（原本繞場景中心，所以感覺中心不對），距離越遠的物體位移越大，跟真的轉頭看出去一致。
- **視線校正（G 鍵／「視線校正」按鈕）**：依序盯 9 個發光圓點（每點約 2 秒、頭不要動），用最小平方法擬合「眼球偏移＋頭部角度＋眼睛位置 → 螢幕座標」的線性模型（往物理預設公式收縮，資料少時不會亂飄），顯示平均誤差（cm）。校正結果存在 localStorage，可「重設校正」。
- **螢幕尺寸校正**：「用信用卡校正螢幕尺寸」會在螢幕上畫一個 8.56×5.4 cm 的虛線框，把真卡片貼上去、拖「螢幕對角線」直到一樣大，不用查螢幕規格。
- 實機尚未驗證：雷射點準確度（取決於校正）、視線牽動強度、攝影機到眼睛的距離仍用「校準距離」。
