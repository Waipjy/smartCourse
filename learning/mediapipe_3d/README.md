# 裸眼 3D 魚缸（head-coupled perspective）

用 webcam 偵測雙眼的位置與距離，即時重畫畫面，讓螢幕像一扇窗：頭往左就看到物體右側、靠近視野變大。
單一檔案 `index.html`，不用安裝；需要 HTTPS 或 localhost 才能開攝影機。

```bash
python -m http.server 8770      # 在這個資料夾，然後開 http://localhost:8770/
```

部署到 GitHub Pages 後在 `https://<帳號>.github.io/<repo>/3d/`。

## 原理

1. **眼睛 3D 位置**：MediaPipe Face Landmarker（478 點含虹膜）。虹膜直徑約 11.7 mm，所以
   `Z = 焦距(px) × 1.17cm ÷ 虹膜像素寬`，再由眼睛在影像中的位置反推 X、Y（攝影機在螢幕上緣外，換算成相對螢幕中心）。
2. **偏軸投影**：螢幕 = 固定在 z=0 的矩形窗，視錐四邊由「螢幕邊緣相對眼睛的位置」決定（Kooima 公式），
   場景單位是公分；盒子牆壁貼齊螢幕邊緣，物體可在螢幕後面（z<0）或浮出來（z>0）。
3. **眼球在眼眶**：虹膜中心相對兩眼角中點的偏移（−1~+1），目前只用來顯示與「視線聚光燈」（實驗）。
   網路攝影機的解析度不夠做精準視線追蹤，所以視差用的是「頭 / 眼睛位置」，不是視線方向。

## 準確度怎麼調

- 設定裡輸入**螢幕對角線**（影響實體大小，決定幾何對不對）與**攝影機視角**（筆電多為 60–75°）。
- 坐在已知距離（例如用尺量 50 cm）按「校準距離」。
- 全螢幕（F）時幾何最準；視窗模式下程式會用視窗位置估計偏移。
- 立體感 >1 會誇張視差（真實感差一點，但更明顯）。

## 驗證狀況

用「滑鼠模擬」和 `window.__setEye(x,y,z)` 驗證過：偏軸投影正確（眼睛往右 → 看到左牆、物體依深度位移不同）；
臉部模型能載入並執行。**真實臉部的距離與位置數值還沒用實際攝影機驗證**（開發環境沒有攝影機）。
