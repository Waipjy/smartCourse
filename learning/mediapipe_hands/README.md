# MediaPipe 手部辨識（手指位置 + 手勢）

跟 HUB 板子、YOLO 都無關的電腦端小專案：用 webcam 即時抓手指位置與手勢。
為什麼不用 YOLO：`yolov7_pytorch` 的 YOLOv7（COCO）只能框出整個「人」，沒有手指關鍵點；手指、手勢要用手部專用模型。

```bash
pip install -r requirements.txt
python 01_hands.py        # 第一次會自動下載手勢模型（約 8 MB，存到 weights/）
```

## 功能

- 每隻手 21 個關鍵點（指尖、指節、手腕）：畫骨架、五根指尖標名稱與像素座標，最多 2 隻手，分左右手。
- 手勢：握拳、張開手掌、食指向上、讚、倒讚、勝利（YA）、我愛你（MediaPipe 模型）＋ OK、搖滾、捏合、數字 0–5（自己的規則，用「指尖比指節離手腕更遠」判斷哪幾根伸直，手轉到哪個角度都能用）。
- 拇指–食指捏合距離（以手掌長度為單位，與手離鏡頭遠近無關）。

## 按鍵

| 鍵 | 功能 |
|---|---|
| ENTER | 拍照，存到 `snapshots/` |
| ESC | 離開 |
| D | 空中繪畫：只伸食指就畫線、比 YA 換顏色、握拳 1 秒清除 |
| R | 猜拳：倒數 3 秒，比石頭（握拳）／剪刀（YA）／布（張開手掌） |
| S / H / C | 骨架顯示／說明／清除畫布 |

## 備註

- 畫面是鏡像的，所以「左手／右手」是你照鏡子看到的那一隻。
- MediaPipe 的 C 函式庫打不開含中文的路徑，所以模型是用位元組載入的。
- 攝影機打不開時，把 `01_hands.py` 開頭的 `CAM_INDEX` 改成 1。
- 驗證狀況：模型下載與載入成功、主迴圈能連續執行；實際辨識準確度與遊戲手感需要你拿手試。
